# NetPilot AI

Enterprise-grade Infrastructure Operations Platform.

## Stack

- **Next.js 16** (App Router)
- **React 19**
- **TypeScript**
- **Tailwind CSS v4**
- **shadcn/ui**

## Status

In active initial development. Frontend-first — no backend yet.

## Roadmap

- **Phase 1** — Project setup: initialize Next.js, Tailwind v4, shadcn/ui
- **Phase 2** — Design system: colors, typography, spacing, and primitives (cards, tables, badges, charts, status indicators, shadows, buttons)
- **Phase 3** — Application shell: sidebar, top navigation, header, breadcrumb, page layout
- **Phase 4** — Dashboard
